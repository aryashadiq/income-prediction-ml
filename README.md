# Income Prediction - Machine Learning

A machine learning project for predicting income category (>50K or <=50K) using the Adult Income Dataset.

## Dataset
- `adult-income-dataset/adult.csv`

## Notebooks
- `Yet_another_copy_of_Income_Prediction_EDA&Prep_Decision_Tree 2.ipynb` - EDA, preprocessing, and Decision Tree model
- `Yet_another_copy_of_Income_Prediction_EDA&Prep_K_Means 2.ipynb` - EDA, preprocessing, and K-Means clustering
- `Yet_another_copy_of_Income_Prediction_EDA&Prep_Naive_Bayes 2.ipynb` - EDA, preprocessing, and Naive Bayes model

## How to Run
1. Clone this repository
2. Install the required dependencies (pandas, scikit-learn, matplotlib, seaborn, etc.)
3. Open the notebooks using Jupyter Notebook or VS Code
